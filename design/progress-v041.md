# 0.41 — первая глава как производственный сценарий

17.10.2026. Предыдущий этап 0.40 — прогресс: создан сценарий пяти глав/25 уровней,
каталог загадок/секретов и бриф живой озвучки. Текущий этап детализирует первую
главу. Новых игровых карт/персонажей/голосов не добавлено, Godot остаётся 0.39.
Общая цель коммерческой игры на 4–5 часов не объявляется достигнутой.

## Материалы

- `chapter1-production-v041.md`: пролог, уровни 01–05, вагон I; присутствие
  людей, маршруты, встречи, последствия, контракт событий и будущая проверка.
- `review/chapter1-layout-v041.json`: пять топологических схем с основными,
  альтернативными, обратными и секретными связями.
- `review/chapter1-v041.html`: интерактивный макет со схемами и читкой.
  Данные встроены; внешних скриптов/шрифтов/изображений нет.
- `voice/chapter1-dialogue-v041.tsv`: 148 уникальных реплик, 40 групп сцен,
  687 слов по всем веткам. У всех `not_recorded`.
- `voice/chapter1-reading-v041.md`: читка тех же строк по сценам.
- `tools/build_scenario_review_v041.py`: повторная сборка макета/читки
  из исходных таблиц, без изменения или импорта карт Godot.

148 строк — редакторский текст первой главы с прологом/необязательными темами,
не полная озвучка кампании. Все 25 уровней остаются частью общего плана.
42 минуты для пяти уровней и 56 с прологом/вагоном — целевые бюджеты,
не оценка по числу реплик и не результат человеческого прохождения.

## Найденное при проектировании

1. Нина должна попасть в защищённый пост до открытия аптеки. Первоначальная
   схема имела связь только из аптеки. Добавлен служебный подход из релейной,
   доступный без включения питания. Документ и схема согласованы.
2. Вагонная сцена проходит на стоянке; команда отправления перенесена в
   конец читки. Машинист не оставляет движущийся состав без управления.
3. Одного открытия жалюзи недостаточно, чтобы спутники вошли внутрь.
   Сцена входа Лиды требует проверенного безопасного подхода (`pharmacy_safe`).
4. Лида на платформе имеет практическую работу: убрать пустые носилки и
   забрать сумку. Её ожидание не сводится к неподвижному моральному испытанию.
5. Раннее «Я видел вас» из исторического черновика не перенесено в эту
   главу. Полный центральный факт остаётся обязательным в главе 2.

Базовая сцена у двери сохраняет личный выход Артёма из кабины. Вариант для
игрока, помогающего сразу снаружи, отмечен как постановочное предложение
для решения до реализации, а не самовольно заменённый канон.

## Исполненная проверка

Сводка/хеши: `output/playwright/scenario-v041/review.json`.
Проверены уникальность ID, связь групп сцен со строками, существование концов
рёбер, связность нарисованной топологии, сумма плановых минут. Это проверки
данных схемы, **не физическая проходимость уровня или достижимость квеста в игре**.

Использован установленный Playwright CLI 0.1.22 из tools/visual-qa.
Новые зависимости и MCP не подключались. Через локальный HTTP в реальном
Chromium-браузере выполнены:
- выбор всех пяти вкладок, по одному скриншоту каждого уровня;
- выбор помещения «Лида / дверь», повтор клавишей Enter, сохранение фокуса;
- выбор читки C1_DOOR: 8 строк, доступно 40 вариантов сцен;
- выключение/возврат секретов: скрытый узел исчез/вернулся;
- выключение/возврат обратного пути: 9 → 8 → 9 связей на схеме 02;
- ширина документа совпала с 1600 и 1366 пикселями;
- просмотр читки C1_OPEN после уточнения условия безопасного подхода;
- консоль страницы: 0 ошибок и 0 предупреждений.

Просмотрены реальные браузерные PNG пяти уровней, читки у двери, читки
открытой аптеки и окна 1366×768. Основные кадры 1600×1000. После первичного
просмотра уточнено только условие/контекст одной строки C1_OPEN, затем эта
сцена отдельно пересмотрена; геометрия пяти схем не менялась.

Прямая навигация `file:` заблокирована настройкой самого CLI. Защита не
отключалась; браузерная проверка шла через временный сервер на 127.0.0.1.
Это ограничение инструмента, не заявление о проверенном открытии файла
во всех пользовательских браузерах. Временный сервер и браузерная сессия
после проверки закрыты.
