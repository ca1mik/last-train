# Аудит и настройка среды — 17 октября 2026

Настройка выполнена. Художественное качество игры и готовность к Steam не приняты.

## Что установлено и применено

- Системные imagegen и skill-creator уже были доступны; повторная установка не нужна.
- Официальные playwright и playwright-interactive установлены из openai/skills.
- Созданы **15** локальных специализированных skills — объединение двух списков
  пользователя. У каждого реальные SKILL.md и agents/openai.yaml, триггеры,
  инструменты, процедура и критерии. **15/15 quick_validate пройдено**.
- Playwright **1.64.1**, CLI **0.1.22**, Chromium **156.0.8078.4**, точные npm-версии,
  lockfile с integrity; скрипты установки пакетов отключены. Официальный CLI имеет
  transitive alpha-зависимость Playwright, она сохранена в lockfile; для браузера
  явно используется установленный стабильным Playwright Chromium.
- Windows-адаптер для Bash-ориентированного CLI skill и пример постоянной сессии.
- Проверенный Blender **5.1.1 / bpy** внутри установленного Blender; отдельный
  pip-bpy или неофициальный MCP не ставился. Godot **4.7.2** оставлен основным движком.
- Семь общих документов в корне и AGENTS.md закрепляют единый процесс.

Полный [индекс skills: пути, назначение, применение и взаимодействие](skills-and-capabilities.md).
Требования и установка сверены с официальными [Playwright docs](https://playwright.dev/docs/intro),
[CLI Microsoft](https://github.com/microsoft/playwright-cli),
[репозиторием Blender](https://github.com/blender/blender/blob/main/doc/python_api/rst/info_quickstart.rst)
и [документацией Godot AnimationTree](https://docs.godotengine.org/en/stable/tutorials/animation/animation_tree.html).

## Дефект, исправленный после замечания пользователя

Старый ключ был привязан к началу Palm.R у запястья, кисть оставалась открытой.
В 0.35 центр хвата вычисляется по MiddleHand/Fingers, ось рукояти ориентируется
в плоскости ладони, поза хвата запечена в клипы. Исходные кисти уменьшены ×0.72
вместе с bind chain и weighted geometry, запястья не перемещены. Старые модели
сохранены в source_25d/authored-v34. Сборка 0.35 запускается через Play.cmd.

Текущий хват проверен в покое и ударе с восьми сторон. Угловатый переход
рукава/кисти остаётся дефектом; это не утверждение готовой профессиональной руки.
Все остальные замечания — [список дефектов](visual-defects-2026-10-17.md).

## Недоступно, не требуется и не выполнено

Поиск каталога Plugin Management по Blender/Playwright/Godot вернул ноль плагинов;
прямых соответствующих MCP среди callable tools не было. Это результат текущего
поиска, не заявление, что таких интеграций нигде не существует.
Playwright контролирует браузер, не нативное окно Godot. CUA браузер доступен,
нативные computer APIs отключены. Прямой ESM import в node_repl дал ошибку;
createRequire проверен настоящим запуском. CLI запрещает file: по умолчанию,
поэтому проверка выполнялась через локальный HTTP на 127.0.0.1.

Three.js/R3F не установлены: в данном проекте нет соответствующего web/React-стека.
Imagegen callable, но новой генерации при настройке не было. Кат-сцены, озвучка,
lip-sync и полные сценарные ветки не объявлены созданными.
Новые skills обнаружатся каталогом на следующем ходе/сессии; в текущем ходе
их файлы и процедуры использованы напрямую.

Нативная сцена при завершении по-прежнему сообщает **7 Texture RIDs leaked**.
Это открытое предупреждение, несмотря на exit code 0.
Эвакуация и длинный первый уровень ещё не реализованы; текущий найденный пациент
не превращён отчётом в спасённого. Многочасовая игра, человеческий playtest и
публикация в Steam остаются незавершённой работой.

Сводка с версиями, SHA256 и scope: `release/capability-audit/summary.json`.
Для просмотра: `release/capability-audit/review.html`; браузерный автоматический
QA запускается через локальный HTTP, нативный — tools/run_capability_native_qa.ps1.
