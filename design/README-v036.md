# Последний рейс · 0.36 · 2.5D

Рабочая первая вылазка мрачного экшена для Windows. Открыть аптеку можно через
мастерскую или релейную; после нахождения Михаила нужно доставить носилки к вагону
по изменившемуся обратному пути. Настоящая ортографическая 3D-сцена, столкновения,
бой, физическая каталка и контрольные точки. Это ещё не готовая к продаже игра:
персонажи, окружение и анимации требуют доводки, остальные главы не перенесены.

## Запуск

[Play.cmd](Play.cmd) запускает `dist/LastTrain-0.36-25D/LastTrain.exe`.
Самостоятельной сборке Python и редактор Godot не нужны; переносить всю папку
с лицензиями. Требуется Vulkan / Forward+.

WASD — движение, Shift — спринт, ЛКМ — направленный удар, пробел / ПКМ —
уклонение, Q — сигнальная ракета, удерживать E — действие, M — схема.
Esc — пауза, F11 — полный экран, R после поражения — контрольная точка.
С носилками можно идти, оставить их для боя и взять снова. Для спасения
нужна реальная доставка к посадочной площадке, не только E в аптеке.

## Проверки

26 проверок базовой игры, 22 — маршрутов/состояний/коллайдеров новой вылазки,
8 — сохранения и загрузки. Сквозные маршруты обеих веток проверяются клавиатурой
и мышью без переноса персонажа/каталки тестом. Это автоматические проверки;
10–15 минут первого человеческого прохождения и несколько часов кампании
не подтверждены. Окружение ещё схематично, базовые Run/Dodge/Hurt/Death не финальные.

## Разработка

`game25d` — активный Godot 4.7.2 проект, стартовая сцена `expedition.tscn`.
`main.tscn` сохраняет прежнюю короткую арену для диагностики.
Сборка: `powershell -File tools/build_25d.ps1 -Version 0.36`.
Проверка доказательств: `python tools/verify_expedition_v036.py`.
Нужны движок и Windows export template из `tools/vendor`.

Текущая игра не импортирует старые 2D-сохранения. Старые исходники сохранены
в `lasttrain`, запуск `python main.py`, проверенная старая сборка 0.31 — в dist.
Сценарий пяти глав хранится в `design/story-bible-ru.md` и документах глав;
наличие этих текстов не означает реализованную кампанию в Godot.

Quaternius — CC0 для исходных персонажей/клипов, Kenney — CC0 для звуков.
Окружение, носилки, материалы и IK создаются в проекте. Источники и изменения:
`game25d/PROVENANCE.md`, `game25d/LICENSES.txt`. Чужие рекламные изображения —
только референсы, они не экспортируются. На выходе Vulkan остаётся известное
предупреждение об утечке 7 Texture RIDs. Steamworks и AppID пока отсутствуют.
