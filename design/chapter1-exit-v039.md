# Глава 1: выход состава — спецификация 0.39

До производства, 17.10.2026. Реализуется сектор D из campaign-v037.md, а не
вся 42-минутная глава. Канон/внешность не меняются. Конкретная геометрия двора
и этапы привода — постановка существующего плана; новые биографии не вводятся.

## Действие и смысл

Михаил остаётся в вагоне. Посадка не означает готовый выход состава. Артём
вместо немедленного ухода в кабину осматривает заевший выходной привод,
обесточивает его, освобождает тягу, вручную переводит и фиксирует положение.
Нина проверяет результат по связи. После технической работы игрок сам
открывает пассажирскую дверь Лиде. Короткая реплика из существующей главы:
«Вы тогда тоже это сказали. Через громкоговоритель». Прямое признание остаётся
главе 2; здесь нет переноса твиста или автоматического прощения.

Спутники пока по рации, без подмены готовых моделей примитивами. Это ограничение
постановки сохраняется. Движущийся рычаг/затвор — механизм, не анимация рук.

## Геометрия и варианты

Новая зона двора X -12..30, Z 22..44 примыкает к платформе и служебному пути.
Оба входа шириной 4 м открываются после посадки через действие у поезда.
До посадки физические створки и навигация не пускают туда, враги не выходят.
Перегородки внутри двора дают верхний и нижний обход, свободный проход >=2 м.
Звонок отвлекает живых врагов в радиусе 28 м на 8 с, кроме уже начатой атаки
или близкого непосредственного контакта. Повтор через 4 с, без расходников.
Альтернативы: проход мимо, отвлечение, бой. Убийства не входят в guards задач.

## Состояния

Все новые поля добавляются к save version 1 с безопасным false для прежних
сохранений. Курсор кампании по-прежнему меняется только при действительном
отправлении; старое завершённое спасение открывает новый сектор, не стирается.

| ID / действие | Условие | Результат и повтор |
|---|---|---|
| C1_EXIT_BEGIN / exit_begin | mission 3 | Оба входа открыты, checkpoint, один раз |
| C1_EXIT_ISOLATE / exit_isolate | begun | Снят привод, гаснет лампа, checkpoint |
| C1_EXIT_CLEAR / exit_clear | isolated | Завал тяги убран, меш исчезает, checkpoint |
| C1_EXIT_THROW / exit_throw | cleared | Рычаг/стрелка меняет положение, checkpoint |
| C1_EXIT_LOCK / exit_lock | thrown | Фиксация, checkpoint; не отменяется повтором |
| C1_LIDA_DOOR / lida_door | locked, у вагона | Дверь открывается, короткая сцена, checkpoint |
| C1_DEPART / depart | дверь открыта, у вагона | Отдельный E, курсор chapter 2, первая глава сохранена |

Уход/урон/движение прерывают текущее удержание E без списания результата;
завершённые этапы сохраняются. Для продолжения после смерти R — последний
checkpoint. Один E не выполняет несколько этапов: требуется отпускание.
